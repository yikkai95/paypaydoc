# Failure / Edge-Case Demo

Last updated: 2026-03-12

| Field | Detail |
|---|---|
| Audience | Swaym |
| Length | 1-2 min |
| Goal | Demonstrate operational maturity and show how the system behaves when things go wrong |
| Main question answered | "What happens when the happy path fails?" |

## Must Include

- permit expired
- insufficient subscriber balance
- Safe approval rejected
- Safe threshold not reached
- allowance exhausted or invalid
- dashboard / notification behavior in each case

## What To Show On Screen

- failed state in dashboard
- approval rejection or pending state in Safe
- any error or retry indicators if available

## What To Avoid

- fake behavior that is not implemented
- too many edge cases in one video if the product UI cannot show them clearly
